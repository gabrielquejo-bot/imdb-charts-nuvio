Addon para Nuvio e Stremio

Quatro listas do IMDb, relidas todo dia.

Séries Populares, Filmes Populares, Top 250 Séries e Top 250 Filmes. Os títulos são lidos das páginas do imdb.com e reescritos a cada 24 horas, sem nenhuma outra fonte no caminho.

No Nuvio: Configurações → Addons → Add Addon → cole o endereço → Install Addon.
